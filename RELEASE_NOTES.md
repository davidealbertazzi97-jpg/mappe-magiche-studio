# Mappe Magiche Studio 1.0.1

## Italiano

Questa versione chiede il consenso prima di caricare immagini esterne contenute in una mappa importata o ripristinata. Il messaggio indica i siti contattati e spiega che possono vedere l’indirizzo di rete e l’ora di apertura. Se il consenso viene rifiutato, gli indirizzi delle immagini esterne vengono rimossi prima di renderizzare o salvare la mappa.

## English

This version asks for consent before loading external images from an imported or restored map. The prompt lists the hosts and explains that they can see the network address and when the map was opened. If consent is declined, external image URLs are removed before the map is rendered or saved.
