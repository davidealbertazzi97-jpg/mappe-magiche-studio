# Font locali

Font WOFF2 incorporati per consentire la scelta dei caratteri anche senza connessione. I file di licenza e le note di copyright originali sono conservati in `licenses/`; i font non sono stati modificati.

Famiglie incluse: Atkinson Hyperlegible Next, Fira Sans, IBM Plex Sans, Inter, JetBrains Mono, Lato, Lexend, Merriweather, Noto Sans, Nunito Sans, Open Sans, OpenDyslexic, Roboto, Source Sans 3, Source Serif 4 e Ubuntu Sans.

Le famiglie Google Fonts sono state scaricate dal repository [google/fonts](https://github.com/google/fonts). OpenDyslexic proviene dal repository pubblico [antijingoist/opendyslexic](https://github.com/antijingoist/opendyslexic); per informazioni e licenza fare riferimento anche al [sito del progetto](https://opendyslexic.org/).

La scelta del carattere è individuale: le etichette aiutano a esplorare stili diversi, senza associare un carattere a una diagnosi o promettere benefici clinici.
